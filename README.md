# runegunp
runegunp (or runegun plus) is a runegun modification that aims to include more content
into the game without the style straying too far off from the original

We've had some difficulties making some features work like leaderboard since it has different stats listed
from the original and accesibility of the original leaderboard requires a Google Play Games account/signed with
the original app's stuff, custom coop with deep floors have not yet been implemented but modes (excluding runeless, one rune, one hit for chaos)
have been AND 4 player
